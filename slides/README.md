# NextGen Mobility — Apresentação Automotiva Premium

Três formatos de apresentação de 12 slides com design automotivo premium, animações dinâmicas e navegação interativa.

## 📦 Arquivos Disponíveis

### 1️⃣ Formato Único (Single HTML File)
**Arquivo:** `../NextGen_Mobility_Complete.html`

- ✅ **Vantagem:** Um único arquivo — fácil de compartilhar, sem dependências
- ✅ **Navegação:** Botões + Setas do teclado (← →)
- ✅ **Contador:** Slide X / 12 no canto inferior direito
- ✅ **Transições:** Suaves animações entre slides
- **Uso:** Duplo clique para abrir no navegador

---

### 2️⃣ Formato Modular (12 Arquivos Separados)
**Pasta:** `./slides/`

Cada slide é um arquivo HTML independente:
- `slide-01.html` — Capa
- `slide-02.html` — Nossa Equipe
- `slide-03.html` — Missão • Visão • Valores
- `slide-04.html` — Análise Ambiental
- `slide-05.html` — Aprendizados
- `slide-06.html` — Indicadores Mercadológicos
- `slide-07.html` — Indicadores Financeiros
- `slide-08.html` — Ranking 3D (Podium)
- `slide-09.html` — Desafios & Aprendizagens
- `slide-10.html` — Cenários Futuros
- `slide-11.html` — Carreira & Competências
- `slide-12.html` — Conclusão

**Vantagens:**
- ✅ Cada slide pode ser aberto independentemente
- ✅ Links diretos para slides específicos
- ✅ Fácil para compartilhar URL de um slide particular
- ✅ Permite customização individual por slide

**Navegação:** Botões de Anterior/Próximo + Link para Índice

---

### 3️⃣ Formato Agregador (Index com Grid de Navegação)
**Arquivo:** `./slides/index.html`

- ✅ **View geral:** Grid com 12 cards dos slides
- ✅ **Navegação visual:** Clique em qualquer card para abrir o slide
- ✅ **Descrições:** Cada card mostra o título e descrição do slide
- ✅ **Design:** Premium com animações hover

**Uso:** Abertura recomendada — oferece visão geral + acesso rápido a qualquer slide

---

## 🎮 Controles de Navegação

### Dentro de cada Slide
| Controle | Ação |
|----------|------|
| **← Seta Esquerda** | Slide anterior |
| **→ Seta Direita** | Próximo slide |
| **Botão ← Anterior** | Volta ao slide anterior |
| **Botão Próximo →** | Avança ao slide seguinte |
| **Link "← Voltar ao Índice"** | Retorna ao index.html |

### No Index.html
| Controle | Ação |
|----------|------|
| **Clique no Card** | Abre o slide em tela cheia |
| **← Voltar ao Índice** | (em cada slide individual) |

## 🚀 Como Usar

### Opção A: Apresentação Única (Recomendada para Full Screen)
1. Abrir `NextGen_Mobility_Complete.html` com duplo clique
2. Usar setas do teclado para navegação
3. Pressionar F11 para modo tela cheia (opcional)

### Opção B: Slides Modulares (Ideal para Links Diretos)
1. Abrir `slides/index.html`
2. Clicar em qualquer card para abrir o slide desejado
3. Navegar entre slides com botões ou setas
4. Compartilhar URL específica de um slide

### Opção C: Visualizar Todos os Slides de Uma Vez
1. Abrir `slides/index.html`
2. Ver grid com preview de todos os 12 slides
3. Clicar para abrir em tela cheia
